---
title: System tray
description: Control what happens when IterVC is closed or minimized.
---

IterVC can remain running in the Windows notification area so routing continues without keeping the main window on the taskbar.

## Close behavior

Choose one of three behaviors in **Settings**:

- **Ask**: show a dialog when the main window is closed.
- **Minimize to tray**: hide the main window and keep IterVC running.
- **Exit**: terminate IterVC and stop its services.

The default persisted behavior is **Ask**.

## Minimize behavior

Enable **Minimize to tray when minimized** to hide the taskbar window when you press the standard minimize button.

## Restore or exit

Use the IterVC tray icon to reopen the main window or exit the application completely. Closing the window to the tray is not the same as exiting.

## First tray notification

The first time IterVC hides to the tray, it can show a notification explaining where the application went. The acknowledgement is stored so the notice is not repeatedly shown.
