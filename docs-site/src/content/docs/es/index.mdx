## Envíe el audio que realmente quiere usar

IterVC captura una copia no destructiva del audio que emiten las aplicaciones seleccionadas. Sus aplicaciones siguen reproduciéndose normalmente por la salida de Windows existente, mientras IterVC crea una mezcla independiente para otro destino.

## Diseñado para que resulte fácil de entender

IterVC se centra en la ruta de audio que la mayoría de las personas necesita sin exigir una mesa de mezcla virtual completa. El procesamiento avanzado de audio de Windows aún puede afectar al sonido capturado; por eso la documentación también cubre el audio espacial, los formatos de sonido envolvente, las mejoras, la latencia, los diagnósticos y los errores frecuentes al seleccionar dispositivos.
